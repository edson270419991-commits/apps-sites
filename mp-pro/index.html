Mp-pro

Painel do administrador para montar e publicar os catálogos do Mp-link e do Mp-cursos.

O que o app faz

  • Importa playlists do YouTube a partir do link ou do ID e deixa você escolher os vídeos.
  • Monta catálogos: álbuns para o Mp-link e cursos com módulos e aulas para o Mp-cursos.
  • Publica o catálogo na pasta correta do repositório do administrador no GitHub.
  • Backup opcional dos catálogos no Google Drive.

Uso restrito

O Mp-pro é uma ferramenta de administração, feita para o próprio desenvolvedor. A publicação no GitHub exige um token de acesso pessoal, que fica guardado somente no aparelho. Veja os detalhes na Política de Privacidade.

Sobre os vídeos

O Mp-pro não hospeda, copia nem baixa vídeos; ele apenas guarda listas de identificadores de vídeos do YouTube. Ao usar o app, você também concorda com os Termos de Serviço do YouTube.
