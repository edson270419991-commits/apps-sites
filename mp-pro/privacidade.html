Política de Privacidade

Última atualização: 27 de outubro de 2026

Esta política explica como o aplicativo Mp-pro ("app") trata informações. Resumindo: não coletamos seus dados pessoais e não temos servidores que os recebam.

1. Informações que ficam no seu aparelho

O app guarda, apenas no armazenamento local do seu aparelho: os catálogos que você monta (nomes, módulos e lista de vídeos), e uma chave de API do YouTube (se você informar). Esses dados não são enviados para nós. Se você desinstalar o app ou limpar seus dados, eles são apagados, a menos que você tenha feito backup no Google Drive ou publicado no GitHub.

2. Informações que não coletamos

Não pedimos nome, e-mail, telefone, localização, contatos, fotos ou qualquer outro dado pessoal. Não há cadastro próprio, anúncios, ferramentas de análise ou rastreamento de uso feitos por nós. O único login do app é a conexão opcional com a sua conta Google, usada só para o backup no Google Drive (veja o item 3).

3. Serviços de terceiros

  • YouTube: para carregar playlists e reproduzir vídeos, o app se comunica com o YouTube (incluindo o player incorporado e, se você informar uma chave, a YouTube Data API v3). Ao usar esses recursos, o Google/YouTube pode coletar dados conforme a Política de Privacidade do Google. O app usa os serviços de API do YouTube e, por isso, você também fica sujeito aos Termos de Serviço do YouTube.
  • GitHub: ao publicar um catálogo, o app envia o arquivo do catálogo para o repositório privado do desenvolvedor, usando um token de acesso do GitHub incluído na versão do app (ou digitado por você no menu). Esse token é usado apenas para falar com o GitHub, que trata os dados conforme a política própria dele. O conteúdo enviado são as listas de álbuns ou cursos, sem dados pessoais.
  • Conta Google e backup no Google Drive (opcional): o backup no Drive só é ativado se você escolher conectar sua conta Google no app. Nesse caso, o app pede estas permissões: drive.file, para criar, atualizar, ler e apagar apenas o arquivo mp-pro-backup.json criado pelo próprio app no seu Drive (o app não consegue ver, ler ou alterar nenhum outro arquivo seu); e e-mail e perfil básico (email e profile), usados apenas para mostrar no app qual conta Google está conectada, sem gravar nem enviar essas informações a ninguém. O arquivo de backup contém os catálogos que você montou e fica na sua conta do Google Drive, onde você pode vê-lo, baixá-lo ou apagá-lo quando quiser. O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Os dados do Google são usados somente para oferecer o backup e exibir a conta conectada; não são usados para publicidade, não são vendidos e não são lidos por pessoas.

4. Chave de API do YouTube e token do GitHub

A chave de API do YouTube é opcional e fica somente no seu aparelho. O token do GitHub é de uso do administrador: ele tem acesso restrito a um único repositório e deve ser tratado como uma senha. Este app é de uso pessoal do desenvolvedor e não deve ser distribuído a terceiros; se o aplicativo for compartilhado ou perdido, o token deve ser revogado no GitHub.

5. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados pessoais, porque não os recebemos.

6. Crianças

O app é uma ferramenta de administração e não é direcionado a crianças menores de 13 anos.

7. Seus direitos e controle

Como os dados ficam no seu aparelho, você pode apagá-los a qualquer momento limpando os dados do app nas configurações do Android ou desinstalando-o. Você pode revogar o acesso do app à sua conta Google em myaccount.google.com/permissions, e revogar o token em Settings → Developer settings no GitHub.

8. Alterações

Podemos atualizar esta política. A data no topo mostra a última revisão.
